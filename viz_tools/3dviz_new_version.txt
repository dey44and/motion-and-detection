Unified browser visualizer · design draft
Extend 3dviz --web into one research workspace. First bring over the full 3ddetviz detection workflow, then add nuScenes LiDAR segmentation. The central interaction is to open a frame, position the camera, and switch between inspecting the scene, reviewing detections, and comparing semantic labels without losing your place.

The preview uses synthetic data. Try switching Ground truth → Prediction, stepping to frame 13 to see how missing labels are shown, or changing the detection confidence threshold.
Workspace
Keep dataset, split, and scene above the viewport and an always-visible frame scrubber, step controls, and frame jump below it. A collapsible inspector has three sections: Scene, Detection, and LiDAR segmentation. Switching sections preserves the frame, camera, and visible layers. Keep dataset configuration and prediction attachments in Sources, so they’re out of the way during review.

Ground-truth boxes and predicted boxes have independent visibility and use solid and dashed outlines, respectively. Semantic coloring applies to the points, with its own class legend, counts, and visibility controls. That lets you inspect a detector’s box and the point classes inside it in the same view.

Put confidence up front and the other filters under Advanced. Reuse the Python review pipeline so browser and desktop apply the same rules. Updating a filter should update only the box layer. The inspector should distinguish a missing prediction frame, a valid empty result, and a result filtered to zero. Acceptance for the first two releases
- Detection parity. Open the same frame, export, and preset in desktop and browser. Verify matching box geometry, retained detections, and filter counts. Changing confidence or NMS preserves the camera and point buffer.
- Segmentation alignment. Compare ground truth with a matching Sonata export on a real nuScenes keyframe. Verify original point order, class mapping, and stable colors across sources. Check that a malformed file or an out-of-order frame response cannot color the wrong scan.
- Waymo compatibility. Exercise native TFRecord, processed OpenPCDet, and paired configurations at each milestone. Verify navigation, box overlays, RGB coverage, and the current behavior for partial acquisition geometry.
